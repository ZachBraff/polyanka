# Полянка 🦖

3D-мир для Луи (2 года): луг в духе Гибли, домик Дино, гостиная с камином,
кухня («покорми Дино») и игровая. Каждая вещь при касании называет себя
по-русски и по-немецки.

- Играть: https://zachbraff.github.io/polyanka/
- Один HTML-файл + Three.js (CDN) + модель KayKit (CC0).
- Управление: тап по земле — Луи идёт сам; ведение пальцем — джойстик; WASD.

Арт: KayKit Character Pack (CC0), прочее — код. Сделано дядей и Клодом.
